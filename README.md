# ai-docker-image

通过 Docker Compose 管理 Claude Code 与 Codex 容器环境的项目。

> 当前处于初始化阶段：仅有文档和忽略规则，尚未提供 Dockerfile、Compose 配置或可运行镜像。

## 目标

- 提供简洁、可维护的双 CLI 容器运行环境。
- 支持通过 SSH 登录宿主机，再进入容器使用 CLI。
- 为工具自身的远程接入保留空间，具体方式及限制在后续设计中确认。
- 将认证状态、项目文件和运行数据与镜像内容分开管理。

文件传输、网络桥接与 FRP 等扩展留待后续讨论，本阶段不预设方案。
